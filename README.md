Πολιτική Απορρήτου της Εφαρμογής Συρμοί Προαστιακού 
Η παρούσα Πολιτική Απορρήτου περιγράφει τον τρόπο με τον οποίο η εφαρμογή Συρμοί Προαστιακού (εφεξής «η Εφαρμογή»), η οποία αναπτύχθηκε από τον/την Alexandros SIozos (εφεξής «ο Προγραμματιστής»), συλλέγει, χρησιμοποιεί και προστατεύει τις πληροφορίες των χρηστών.
1. Συλλογή και Χρήση Πληροφοριών
Η Εφαρμογή έχει σχεδιαστεί για να παρέχει τη βέλτιστη δυνατή εμπειρία χρήσης.
• Η Εφαρμογή δεν συλλέγει, δεν αποθηκεύει και δεν μοιράζεται κανενός είδους προσωπικά δεδομένα ή πληροφορίες που μπορούν να ταυτοποιήσουν τον χρήστη.
2. Υπηρεσίες Τρίτων (SDKs)
Η Εφαρμογή χρησιμοποιεί υπηρεσίες τρίτων που ενδέχεται να συλλέγουν πληροφορίες για την ταυτοποίηση της συσκευής σας. Παρακάτω μπορείτε να διαβάσετε τις πολιτικές απορρήτου των παρόχων που χρησιμοποιούνται:
• Google Play Services
3. Δικαιώματα Χρηστών και Διαγραφή Δεδομένων
Οι χρήστες διατηρούν όλα τα δικαιώματα που προβλέπονται από τον Γενικό Κανονισμό Προστασίας Δεδομένων (GDPR). Εάν η εφαρμογή επιτρέπει τη δημιουργία λογαριασμού, μπορείτε να ζητήσετε τη διαγραφή του λογαριασμού και των δεδομένων σας ανά πάσα στιγμή στέλνοντας email στο alexander.siozos@gmail.com.
4. Αλλαγές στην Πολιτική Απορρήτου
Ο Προγραμματιστής ενδέχεται να ενημερώνει την παρούσα Πολιτική Απορρήτου κατά καιρούς. Σας συμβουλεύουμε να ελέγχετε αυτή τη σελίδα περιοδικά για τυχόν αλλαγές.
